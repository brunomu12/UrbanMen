Mejoras implementadas – Urban Men

Durante el desarrollo del proyecto Urban Men se incorporaron diferentes mejoras con el objetivo de ofrecer una mejor experiencia de usuario y ampliar las funcionalidades del ecommerce.

1. Implementación del carrito de compras

Se desarrolló un carrito de compras que permite agregar productos seleccionados y visualizar la información de cada artículo.

2. Modificación de cantidades

Se incorporaron botones para aumentar y disminuir las unidades de cada producto, tanto en las tarjetas como dentro del carrito.

3. Cálculo automático de importes

Se implementó el cálculo automático de los subtotales de cada producto y del total general del carrito, actualizándose cada vez que se modifica una cantidad.

4. Almacenamiento de datos

Se incorporó localStorage para conservar los productos agregados al carrito, incluso cuando se actualiza la página.

5. Mejoras en la interfaz

Se realizaron ajustes visuales para mejorar la presentación de las tarjetas de productos, centrar sus elementos y mantener visible el resumen del carrito en la parte inferior de la pantalla.

Conclusión

Estas mejoras permitieron transformar el proyecto inicial en un ecommerce más completo e interactivo, facilitando la navegación y la selección de productos por parte de los usuarios.
