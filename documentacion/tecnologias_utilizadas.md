Tecnologías utilizadas – Urban Men

1. HTML5

Se utilizó HTML5 para desarrollar la estructura del sitio web. Se crearon las diferentes páginas del ecommerce, incluyendo la página principal, las categorías de productos, el inicio de sesión, el registro y el carrito de compras.

2. CSS3

Se utilizó CSS3 para diseñar y dar identidad visual al sitio. Se definió una paleta de colores basada principalmente en negro, dorado y blanco, buscando una estética moderna relacionada con la indumentaria masculina.

También se utilizaron estilos para organizar las tarjetas de productos, los formularios, la barra de navegación y adaptar el diseño a diferentes tamaños de pantalla.

3. JavaScript

Se incorporó JavaScript para agregar funcionalidades e interactividad al ecommerce. Se utilizó para crear componentes reutilizables, generar dinámicamente las tarjetas de productos, implementar la navegación y desarrollar las funcionalidades del carrito de compras.

También se implementaron funciones para aumentar y disminuir las cantidades de productos, eliminar artículos y calcular los importes.

4. JSON

Se utilizó JSON como estructura de almacenamiento de los datos de los productos. Esta tecnología permite organizar la información mediante propiedades como nombre, descripción, precio, imagen y categoría.

Se eligió porque facilita la organización y actualización de los productos, permitiendo que JavaScript utilice esos datos para generar las tarjetas correspondientes.

5. localStorage

Se utilizó localStorage para guardar los productos agregados al carrito en el almacenamiento local del navegador. De esta manera, los productos seleccionados permanecen guardados al actualizar o volver a abrir la página desde el mismo navegador.

6. Git y GitHub

Se utilizó GitHub para almacenar y gestionar el código fuente del proyecto, permitiendo guardar las distintas modificaciones realizadas durante el desarrollo.
