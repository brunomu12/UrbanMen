 ## Descripcion del proyecto

 UrbanMen es una aplicacion web de comercio electronico orientada a la venta de ropa masculina.
 Esta aplicacion corresponde a la primera etapa del trabajo practico de e-commerce.
 En esta primera etapa se desarrollo la estructura general del sitio utilizando HTML.
